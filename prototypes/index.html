Samaltak — UI directions

Four clickable prototypes. Same evaluator and class library underneath; only the interaction model differs.

1Classic revival

Overlapping windows, 4-pane System Browser, Workspace, Inspector, Process Browser. Smalltalk-80 lineage, modern craft.

2Infinite canvas

One zoomable plane of live cards. Inspecting spawns connected cards; semantic zoom reveals the layer structure.

3Acme-style tiling

Columns of text panes. All text is executable; click a name to browse it. Keyboard-first, zero chrome.

4Spatial Morphic

Halos on every widget, windows flip to show their implementation, 3D x-ray of the rendering layers.

Classic revival — themes

Same prototype, different palette and typography. Switch live with the top-bar theme button or ⌘⇧T; Aa swaps in pi-orb's typefaces (Iosevka Etoile + JetBrains Mono) over any theme.
