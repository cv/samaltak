# Platform layer (C)

SDL3 windows/input, SDL_GPU (Metal), files, sockets. No policy, no rendering logic. `prims_platform.def` (400–699) lists every primitive with its arguments; `prims_platform.c` documents event and keycode details; `platform.h` is the C API. Tests: `make -C vm/platform test` (C internals + primitives against a mock vm.h), `make -C vm/platform st-test` (Smalltalk through the real VM).

**Conventions.** Arguments are positional and the receiver is ignored. Handles are SmallIntegers. Byte buffers are ByteArray/ByteString (Bitmap where noted). `start` is 1-based. Pairs come back as Arrays (`{w. h}`). A primitive fails on bad arguments or OS/GPU errors, and `platformLastError` then returns the message (Metal shader compile errors included).

**Primitives.**
- Window: `windowOpen` (w h title flags: 1 hidden, 2 resizable, 4 highDensity), `windowClose`, `windowSize` (points), `windowPixelSize`, `windowDisplayScale`, `windowRefreshRate`, `windowSetTitle`, `windowShow`, `windowHide`, `setCursor` (0 arrow, 1 ibeam, 2 hand, 3 ew, 4 ns, 5 nwse, 6 nesw, 7 move, 8 wait, 9 crosshair, 10 notAllowed), `clipboardGet`, `clipboardSet`.
- Input: `nextEvent:` (8-slot Array; returns it filled, or nil), `injectEvent:` (same format, same queue), `inputSemaphore:`, `vsyncSemaphore:`, `droppedEvents` (events dropped since startup because the queue was full; `Smalltalk vm droppedEvents`). The queue holds at most 4096 events (`PF_EVENT_QUEUE_MAX`); further OS or injected events are dropped (injecting still succeeds).
- GPU: `gpuCreateDevice`, `gpuClaimWindow`, `gpuSwapchainFormat`, `gpuCreateShader` / `Pipeline` / `Texture` / `Sampler` / `Buffer`, `gpuRelease`, `gpuUploadBuffer` / `Texture`, `gpuAcquireCommandBuffer`, `gpuAcquireSwapchain` (`{tex. w. h}`, or nil when hidden/minimized or too many frames are in flight), `gpuBeginPass` (clear `{r. g. b. a}`, or nil to load) → pass, `gpuSetViewport`, `gpuSetScissor`, `gpuBindPipeline`, `gpuBindVertexBuffer`, `gpuBindTexture`, `gpuPushUniforms`, `gpuDraw`, `gpuEndPass`, `gpuBlit`, `gpuSubmit` (→ fence or nil), `gpuWaitFence`, `gpuFenceDone`, `gpuDownload` (synchronous, into a caller buffer; RGBA8, R8 = 1 byte), `gpuTextureSize`, `gpuWaitIdle`.
- Files: `fileOpen` (0 read, 1 readWrite, 2 append, 3 createTruncate), `fileClose`, `fileRead`, `fileWrite`, `fileSize`, `filePosition`, `fileSeek`, `fileFlush`, `fileDelete`, `fileRename`, `fileStat` (`{exists. isDir. size. mtimeµs}`), `dirEntries`, `dirCreate`, `cwd`, `mkfifo`, `spawnProcess` (argv Array, PATH lookup) → pid, `processWait` (pid block → status, or nil while running), `fileWriteBehind` (like `fileWrite`, but the bytes are copied and written by a background thread, so a slow reader such as a FIFO into ffmpeg never blocks the VM; answers 0 while 3 writes are pending; `fileFlush`/`fileClose` wait for them; an error shows up on the next call).
- Sockets: `socketListen` (host port backlog; port 0 picks a free one), `socketConnect`, `socketAccept` (nil if none), `socketRecv` (0 at EOF, nil = would block), `socketSend` (nil = would block), `socketClose`, `socketSemaphore` (sock readIdx [writeIdx]), `socketLocalPort`.
- Formats: texture 1 r8, 2 rgba8, 3 bgra8. Texture usage bits: 1 sampler, 2 colorTarget. Buffer usage: 1 vertex. Shader stage: 0 vertex, 1 fragment. Blend: 0 none, 1 alpha, 2 premultiplied. Primitive type: 0 triangles, 1 strip, 2 lines, 3 lineStrip, 4 points. Vertex attributes `{fmt. offset. ...}`, where fmt is 1 float, 2 float2, 3 float3, 4 float4, 5 ubyte4norm, 6 ubyte4, 7 uint, 8 int. Attribute i becomes location i in vertex buffer slot 0.

**Events** `[type, timeMs, x, y, buttonOrKey, modifiers, textOrDelta, windowId]`. Coordinates are Float points. Modifiers: shift 1, ctrl 2, alt 4, cmd 8. Type codes: 1 mouseMove, 2 mouseDown, 3 mouseUp, 4 wheel (delta is a Point), 5 keyDown, 6 keyUp (SDL keycode; delta is the repeat flag), 7 textInput (String), 8 windowResized (x@y = new size), 9 windowCloseRequest, 10 quit, 11 focusGained, 12 focusLost, 13 displayScaleChanged (x = scale), 14 mouseLeave, 15 windowExposed. mouseDown/Up carry the click count. Injecting with timeMs nil means "now".

**Semaphores.** Each semaphore is signaled once when something is pending, then stays quiet until re-armed. `nextEvent:` and `socketRecv`/`socketAccept` re-arm. A send that would block, or sends only part of the data, arms the write semaphore. So drain until nil, then wait.

**Uploads** are batched into one copy pass per device. The batch is submitted at the next `gpuSubmit`/`gpuDownload`, so it runs before that command buffer. Upload before recording the frame that uses the data. `gpuDownload` only sees work from command buffers that were submitted before it.

**MSL on SDL_GPU/Metal.** Entry points must not be named `main`; use names like `vmain`/`fmain`.
- Vertex shader: read inputs through `[[stage_in]]` with `[[attribute(i)]]`. Vertex buffer slot 0 is `[[buffer(14)]]` internally; don't write it by hand. Uniform slot n is `[[buffer(n)]]`.
- Fragment shader: sampled texture slot n is `[[texture(n)]]`, paired with `[[sampler(n)]]`. Uniform slot n is `[[buffer(n)]]`. Storage buffers come after the uniforms, storage textures after the sampled textures.
- Uniforms are pushed per command buffer with `gpuPushUniforms` and stay in effect for later draws. Pad structs to 16 bytes.
- NDC has y up; texture and framebuffer pixel origins are top-left.

**Present.** Metal offers VSYNC and IMMEDIATE, not MAILBOX, so `gpuClaimWindow` picks IMMEDIATE. Even so, `nextDrawable` blocks when the app outruns the window server. On a 120 Hz ProMotion display, presenting on every vsync blocked each acquire for 4–9 ms. Presenting on every second `vsyncSemaphore` signal (60 Hz) kept acquires at about 0.03 ms. The compositor should present at ≤ 60 Hz, or skip frames when nothing changed. Swapchain textures are write-only, so render into an offscreen RGBA8 texture, blit it to the swapchain, and read back the offscreen one.

**Measured** on an M2 Max, 2880×1800 RGBA8 frame: upload 0.7 ms, render 0.5 ms, download 1.0 ms.

**VM hooks.** `pf_events.c` defines `platform_init`, `platform_poll` (pumps SDL at most once per ms, polls sockets, signals semaphores), `platform_wait(µs)` and `platform_shutdown`. These override the VM's weak defaults (`vm/src/vm.h`). Since the VM only checks interrupts when something is due, the platform calls `request_periodic_poll(PF_POLL_US)` (1 ms) once video is initialized or a socket has a semaphore, so `platform_poll` keeps pumping input and sockets while Smalltalk computes; while the VM idles, the wait itself returns on events. The wait blocks in `SDL_WaitEventTimeout`; a helper thread poll()s the armed sockets and the CVDisplayLink thread wakes it. Headless, it uses poll() alone. Link with `-lSDL3 -framework CoreVideo`. All calls run on the main thread.
