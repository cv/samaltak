How to read this catalog

Necessity The current contract needs VM state, image semantics or a target-specific service; an ordinary approved native call alone would not preserve it.

Policy A dedicated native interface could be designed, but migration is not justified or would change the authority boundary. The tags classify retention here, not what could ever be implemented.

Scope: the audit’s Keep IDs, not all 206 entries in the hosted SDL registry. For example, 422 (windowSetPosition) is registered but outside the original audit, as are the fork’s 21 primitives, added after it. Approved FFI export IDs are separate. Registration does not guarantee implementation on every target.

Match an exact ID or search by name, family or reason. Print always includes the full catalog.

SmallInteger arithmetic · 19

These entries use tagged SmallInteger operands. The JIT can inline common operations; a failed tag or range check takes the Smalltalk fallback.

ID / Registered nameWhy it stays
1 intAddNecessity Adds two SmallIntegers; a sum outside the tagged range must fail so the image can promote it.
2 intSubNecessity Subtracts two SmallIntegers; a difference outside the tagged range takes the image fallback.
3 intLessNecessity Tests signed less-than on two SmallIntegers and returns the image Boolean; other operand types fall back.
4 intGreaterNecessity Tests signed greater-than on two SmallIntegers and returns the image Boolean; other operand types fall back.
5 intLessEqNecessity Tests signed less-than-or-equal, including the equal case; both operands must have the SmallInteger tag.
6 intGreaterEqNecessity Tests signed greater-than-or-equal, including the equal case; both operands must have the SmallInteger tag.

8 intNotEqNecessity Tests numeric inequality on two SmallIntegers; a non-SmallInteger operand fails rather than implying inequality.
